# 주소 검색 API

`GET /api/addresses/search?keyword={URL 인코딩한 검색어}`

기존 API와 동일하게 `Authorization: Bearer {accessToken}`이 필요합니다.
검색어 앞뒤 공백을 제거하며 1~100자를 허용합니다.

```json
{
  "code": "SUCCESS",
  "message": "요청이 성공적으로 처리되었습니다.",
  "data": [
    {"name": "홍익대학교 제2기숙사", "address": "서울 마포구 와우산로 94 홍익대학교", "x": 126.9256, "y": 37.5515}
  ]
}
```

위 결과는 응답 형식 예시이며 실제 검색 결과를 보장하지 않습니다.
카카오맵 키워드 검색에서 최대 5개 장소 후보를 조회합니다. 도로명 주소가 없으면 지번 주소를 사용합니다.
좌표는 WGS84 경도(x), 위도(y) 숫자입니다. 기존 등록 조건에 맞지 않는 결과는 제외합니다.
검색 결과가 없으면 `data: []`를 반환합니다. 검색으로 DB에 저장하지 않습니다.

프론트는 목록에서 사용자가 선택한 항목을 기존 `POST /api/addresses` 본문으로 전달합니다.
검색어 변경 시 선택을 해제하고, 선택 전 등록을 막아 주세요. 연속 입력은 약 300ms debounce하고
이전 검색 응답이 최신 결과를 덮어쓰지 않도록 처리해 주세요.

## 서버 설정

카카오 개발자센터에서 카카오맵 사용 설정을 ON으로 설정한 앱의 REST API 키를 서버 환경변수로 설정하고 서버를 재시작합니다.

- `KAKAO_REST_API_KEY`

JavaScript 키나 어드민 키가 아닌 REST API 키를 사용합니다. 키를 프론트나 Git에 넣지 않습니다.
미설정 상태에서도 서버는 시작하지만 검색 호출은 HTTP 503 / A005를 반환합니다.
외부 API 오류, 호출 한도 초과, 잘못된 응답, 시간 초과도 503 / A005로 처리합니다.
공백 또는 100자 초과 검색어는 400 / C002, 파라미터 누락은 기존 공통 예외 처리에 따릅니다.
연결 제한 시간은 3초, 읽기 제한 시간은 5초입니다. 자동 재시도는 하지 않습니다.

이 API는 업체·기관 등 장소 후보 검색입니다. 일반 도로명·지번 주소 검색을 위한
카카오 주소 검색 API 연동, 오타 교정, 별도 요청 횟수 제한 및 캐시는 포함하지 않습니다.
기존 transit 경로 검색 API는 변경하지 않습니다.

참고: https://developers.kakao.com/docs/ko/kakaomap/rest-api

외부 요청은 대한민국 좌표 범위(rect=124,33,132,39), 정확도순, 최대 5개로 제한합니다.
