# 카카오 경로의 서울 버스 첫차·막차 알림

## 지원 범위

- 카카오 경로 중 BUS 구간 1개와 선택적인 앞뒤 WALK 구간만 지원한다. 환승, 지하철, 시외버스는 제외한다.
- 서울 API의 노선 유형 2~6(마을·간선·지선·순환·광역)만 허용한다. 경기·인천 노선은 서울 정류장을 경유해도 제외한다.
- 출발/도착 정류장은 서울 주변 좌표 범위 안에 있어야 하며 실제 API 검색 결과로 확인한다. 좌표 사각형만으로 서울 정류장이라고 판정하지 않는다.
- 기존 ODsay 경로의 시간표 처리와 NORMAL 알림 계산은 유지한다.

## 검증 및 계산

1. `getStationByPos`로 탑승·하차 정류장 주변 100m를 검색한다. 정류장 이름과 WGS84 거리를 확인한다.
2. `getRouteByStation`에서 버스 번호와 서울 노선 유형을 확인한다.
3. `getStaionByRoute`에서 탑승·하차 ID, 전체 경유 정류장 이름의 연속 순서, 중간 회차 여부를 확인한다. 일치하는 방향이 정확히 1개일 때만 허용한다.
4. `getBustimeByStation`의 `arsId`/`busRouteId`를 대조하고 `firstBusTm`/`lastBusTm`을 읽는다.
5. **알림 시각 = 정류장 첫차/막차 예정시각 − 탑승 전 도보시간 − 미리 알림 시간**이다. 하차 후 도보시간은 차감하지 않는다.

생성·수정 시 시간표를 검증하고, 스케줄러가 운행일마다 다시 검증하여 기존 snapshot 테이블에 저장한다. source는 `SEOUL_BUS`다. 이번 기능은 예정시간 기반이며 실시간 보정이나 첫차를 놓친 뒤 다음 버스 복구 알림은 적용하지 않는다.

서울 시간표 API는 **금일 정보**이며 요청에 날짜 인자가 없다. 미래 날짜의 시간표를 보장하지 않는다. 반복 알림도 해당 운행일에 조회 가능한 시간표만 사용한다. 타임스탬프에 다른 날짜가 들어 있거나 값이 없으면 거절한다. 시간만 제공된 막차가 첫차보다 이르면 다음 날로 처리하며 24시 이상 표기도 처리한다.

자정을 넘긴 막차는 전날 snapshot과 전날 반복요일을 기준으로 발송한다. 전날 snapshot이 없으면 오늘 응답을 어제 시간표로 대체하지 않는다. 따라서 전날 시간표 확보 전에 서버가 중단되었거나 자정 이후 처음 등록한 경우 직전 운행일 막차는 보장되지 않는다.

성공한 매칭·시간표 조회는 날짜와 경로별 30분 캐시를 사용한다. 오류 발생 시 전체 서울 시간표 클라이언트에 60초 재시도 대기를 적용한다. 캐시 최대 1,000개, HTTP 연결 3초/읽기 5초 제한이다.

## 응답과 설정

- 요청 형식은 기존 FIRST_TRANSIT/LAST_TRANSIT와 같다. targetArrivalTime은 생략 가능하다.
- 경로 후보 전체(provider, 정류장 목록, 양 끝 좌표 포함)를 routeDetails로 저장해야 한다.
- `422 T005`: 지원 범위 밖, 방향 불명확, 정류장/시간표 매칭 실패.
- `503 T006`: 서울 API 인증/한도/통신/잘못된 응답 등 조회 실패. 등록·수정은 저장되지 않는다.
- 키: `publicdata.seoul.schedule-key`, 생략 시 기존 `publicdata.api.key` 사용. 키를 코드나 문서에 기록하지 않는다.
- 정류소 서비스 집계는 `SEOUL_STATIONS`, 노선별 정류장 조회는 `SEOUL_ROUTES`다. 실제 승인 한도는 각각 `API_DAILY_LIMIT_SEOUL_STATIONS`, `API_DAILY_LIMIT_SEOUL_ROUTES`로 지정한다.
- DB 마이그레이션은 추가하지 않았다.

## 운영 전 확인

2026-09-18 두 서비스의 활용승인을 완료했으며 승인 정보 반영을 기다리는 중이다(안내된 예상 시간 1~2시간). 반영 후 기존 키로 정류장·노선·시간표를 재조회해야 한다. 시간표 API가 성공하기 전에는 T006으로 등록이 거절된다.

- [서울특별시 정류소정보조회 서비스](https://www.data.go.kr/data/15000303/openapi.do): getStationByPos, getRouteByStation, getBustimeByStation
- 서울특별시 노선정보조회 서비스: getStaionByRoute (기존 서울 노선 동기화에서 사용)

공식 시간표 설명: [서울 정류소별 노선 첫차/막차 예정시간](https://data.seoul.go.kr/dataList/OA-15334/L/1/datasetView.do). 현재 명세의 시간 필드 이름과 '금일' 의미는 공공데이터포털의 상세 기능 getBustimeByStationList에서 확인했다.
